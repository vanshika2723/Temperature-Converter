# 🌡️ Temperature Converter

A simple and responsive **Temperature Converter** web application built using HTML, CSS, and JavaScript.

The application allows users to convert temperatures between **Celsius, Fahrenheit, and Kelvin** in real time.

## 🚀 Live Demo

https://vanshika2723.github.io/Temperature-Converter/

## 📌 Features

- 🌡️ Convert Celsius to Fahrenheit and Kelvin
- 🔥 Convert Fahrenheit to Celsius and Kelvin
- ❄️ Convert Kelvin to Celsius and Fahrenheit
- ⚡ Real-time temperature conversion
- 🔄 Reset button to clear all inputs
- ✅ Temperature validation
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
